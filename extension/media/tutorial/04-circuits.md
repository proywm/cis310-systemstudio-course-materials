# Predict, build, inspect, test

Use a small concept-to-circuit loop:

1. Read the mapped bundled presentation.
2. Predict one input/output row or state transition.
3. Create a blank or assignment-specific circuit.
4. Inspect its preview and run available tests.
5. Integrate the component only after the evidence matches the prediction.

Remote SSH supports preview and tests; the native Digital graphical editor needs local desktop VS Code.
