# One embedded teaching environment

Use **Auto-detect**, **Irvine32 Classroom**, or **NASM IA-32** without installing Docker or a host assembler. Build and step while observing registers, flags, memory, stack, virtual-console input, output, and the recent trace.

When stuck, ask the local Student Helper. It routes topic, tool, and submission questions to evidence; it does not know current deadlines, grade work, or submit to Canvas.
