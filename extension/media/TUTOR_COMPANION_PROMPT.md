# Orbit tutor-companion asset record

`tutor-companion.png` is an original project asset generated with OpenAI's
built-in image-generation tool on August 20, 2026. It was not copied or adapted
from VS Code Pets. The public VS Code Pets project informed only the general
idea that a playful optional companion can make a VS Code panel feel more
inviting.

Final prompt:

> Use case: stylized-concept. Asset type: optional animated AI
> learning-assistant mascot inside a university computer-architecture VS Code
> extension. Create one original friendly anime-inspired owl-and-microchip
> tutor character, suitable as a small chat companion and circular avatar.
> Transparent isolated background; small gender-neutral owl robot; subtle
> processor-chip chest emblem; warm attentive expression; one wing raised as
> if inviting a question; polished 2D educational cel shading; readable at 96
> pixels; centered square; maize-gold, deep-navy, and muted-teal palette; high
> contrast in light and dark themes. No text, logos, university seal,
> watermark, copied VS Code Pets character, photorealism, weapons, sexualized
> features, or excessive detail.

The webview supplies animation in CSS. The image remains meaningful only as
decoration: the chat button has a text accessible name, the help choices are
ordinary HTML, motion can be paused, and `prefers-reduced-motion` disables it.
