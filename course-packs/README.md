# Course Packs

This is the entry point for course content integrated with SystemStudio.

## Available pack

- [`cis310-fall2025/`](cis310-fall2025/README.md) — CIS 310 reference pack containing 13 mapped presentation entries and four locally packaged assignments.

The current pack is marked **instructor review required**. It preserves historical Fall 2025 source material for preparation and testing; current Canvas instructions, deadlines, points, and submission rules remain authoritative.

## Structure

Start with the pack README, then use its student guide, machine-readable manifest, assignment copies, and source audit:

1. [`cis310-fall2025/README.md`](cis310-fall2025/README.md)
2. [`cis310-fall2025/STUDENT_MATERIALS.md`](cis310-fall2025/STUDENT_MATERIALS.md)
3. [`cis310-fall2025/materials-manifest.json`](cis310-fall2025/materials-manifest.json)
4. [`cis310-fall2025/source-audit.md`](cis310-fall2025/source-audit.md)

Student records, submissions, grades, exams, answer keys, hidden tests, and completed assignment solutions must not be added to a course pack.
