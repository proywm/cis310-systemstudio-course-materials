Beginning-of-course pre-test: number representations

0 points; not graded. Your result does not affect your course grade. This diagnostic helps the instructor see what the class already knows and what needs additional explanation.

Before you begin

  • Make one honest attempt using only your current knowledge. Do not use an AI assistant, converter, completed solution, or another person’s code.
  • It is fine not to know how to complete every part. That information is useful for planning the course.
  • Canvas records your identity and submission. Any class-level summary will be reported in aggregate.
  • This is a baseline diagnostic, not a test of material you were expected to learn before this course.

Programming task

Write a program in C or C++ that prints every decimal integer from 0 through 255, inclusive, together with these three representations:

  1. Binary: exactly 8 bits, displayed as two groups of 4 bits.
  2. Hexadecimal: exactly 2 digits. Uppercase or lowercase letters are acceptable.
  3. Binary-coded decimal (BCD): treat the decimal value as three decimal digits from 000 through 255; encode each decimal digit separately as 4 bits, including leading zero digits.

Use computation or formatting logic to produce the conversions. Do not hard-code a table containing all 256 answers.

Required output format

Use a monospaced, aligned table with one heading row and 256 data rows. The beginning should follow this pattern:

Required output pattern for the first three values
Decimal Binary Hexadecimal BCD
0 0000 0000 00 0000 0000 0000
1 0000 0001 01 0000 0000 0001
2 0000 0010 02 0000 0000 0010

Your program must continue through decimal 255. The table above defines formatting only; it does not provide the complete solution.

What to submit in Canvas

Submit:

  1. your .c or .cpp source file; and
  2. a plain-text or PDF capture of the program’s output for the heading and the rows for decimal values 0–20, 99–101, 210–212, and 253–255.

If Canvas accepts only one file, place both items in one .zip file. Use the Pre-test: Number Representations Canvas assignment so your submission receipt is recorded.

Accessibility or setup barrier

If you cannot run a C/C++ compiler or cannot use the required submission format, contact the instructor promptly. Describe the operating system, what you attempted, and the exact error or access barrier. The diagnostic remains ungraded.
