# CIS 310 Homework 2: Sequential Logic and State Machines

## Preparation

Review Lecture 6 on latches, flip-flops, clocks, sequential circuits, and counters. Work through each state transition before constructing a circuit.

## Study tasks

1. Determine the value of `Q` for the circuit diagram provided in the official assignment.
2. Construct characteristic tables for SR, D, JK, and T flip-flops.
3. Construct the corresponding excitation tables.
4. Determine the number of latches required to represent 19 states.
5. Determine the maximum number of states representable with five latches.
6. Design a two-bit up/down counter.
7. Derive a logic circuit from the provided next-state and output expressions.
8. Derive truth and output tables from the provided state diagrams.
9. Design a finite-state machine that detects the bit sequence `110`.

The source contains diagrams that are not reproduced in this text-only reference. Open the current Fall 2026 Canvas assignment for those diagrams and for the exact required notation. Do not guess from missing figures.
